# Document Translator App

A web application that allows users to **translate text documents and images** into different languages with ease. Built using **Next.js**, this app provides a simple drag-and-drop interface for uploading files, previewing translations, and downloading translated content.

---

## Features

- **Translate Text Documents**  
  Supports `.txt`, `.md`, `.docx`, and `.pdf` files. Extracts text from uploaded documents and translates it to the target language.

- **Translate Images**  
  Upload images (e.g., `.jpg`, `.png`) containing text. The app extracts the text via OCR (Optical Character Recognition) and translates it while leaving the rest of the image intact.

- **Preview Translations**  
  Users can see the translated text immediately in a scrollable preview box.

- **Download Translations**  
  Download translated content as a `.txt` file for easy offline use.

- **Simple Drag-and-Drop UI**  
  User-friendly interface powered by **React Dropzone** for quick file uploads.

- **Powered by AI Translation Models**  
  Uses a custom **Gradio translation model** for accurate and efficient language translation.
